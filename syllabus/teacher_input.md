This file contains the teacher input for the classes

Background:
- kids do not have computer science background or programming experience.


Goals of the 6 to 8 week classes
- Manual programming is a dieing art. The goal is not to teach programming.
- The goal is to teach gen ai and vibe coding so the kids can build software application or games afterwards.

# Suggested teaching plan

## Basics
- While programming is dead, the kids should still understand how a computer program works.
- kids should learn how internet works
- kids should learn different components of a software application like frontend, backend, and database
- kids should learn different components of a laptop based video game
- kids should learn different components of a laptop based video game with internet connected players
- Kids should learn the difference between ML, AI, and Gen AI
- ML should be briefly introduced using simple concepts like linear regression since they know algebra and formula.
- Using simple linear regression, kids should learn ML training, testing, and inference.


## Intermediate
- Kids should understand neural network and this should be taught in relation to human brain. They should learn how neural networks learn, retain knowledge and use the knowledge to predict something.
- Build on top of neural networks and introduce LLM. Explain each word in LLM and GPT.
- Introduce autoencoding and autoregressive models to middle schoolers as language understanding and language generation models.
- Introduce basics of prompt engineering and explain how a prompt works.
- Show kids how to build a simple presentation or report using prompt engineering.
- show kids how to use additional context (files) and create a school report or article.

## Advanced
- show kids how to build a web application using vibe coding
- Capstone project: Guide each kid in building their idea.
