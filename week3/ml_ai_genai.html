AI vs. ML vs. Gen AI

They're related — like Russian nesting dolls. Click each circle to learn more!

AI
Artificial Intelligence
ML
Machine Learning
Gen AI

AI (Artificial Intelligence) — The big umbrella. Any machine that can do things that seem smart: play chess, filter spam, understand your voice, recommend videos. AI has existed since the 1950s!

ML (Machine Learning) — A type of AI where machines learn from data instead of being manually programmed with every rule. You show it examples, and it figures out the pattern on its own.

Gen AI (Generative AI) — A type of ML that can create new content: write essays, generate images, compose music, write code. ChatGPT and Claude are Gen AI!

The rule: All Gen AI is ML. All ML is AI. But NOT the other way around!

You Already Know ML!

Remember this from algebra class?

y = mx + b

In Algebra Class

y = answer
m = slope
x = input
b = y-intercept

In Machine Learning

y = prediction
m = weight (learned!)
x = input data
b = bias (learned!)

Mind-blowing fact: The simplest ML model in the world is literally y = mx + b. It's called Linear Regression. You already know the math behind machine learning!

The 3 Steps of Machine Learning

What we just did on the graph follows a pattern every ML model uses:

📚

1. Training

Learn from data

➡️
🧪

2. Testing

Check if it works

➡️
🔮

3. Inference

Make predictions

Training = Finding the best line. We gave the model our data (hours studied + test scores) and it found the values of m and b that make y = mx + b fit the data as closely as possible. Like studying for a test — the model is "studying" the data!

Testing = Checking with new data. We hold back some data the model hasn't seen. If the model predicts those scores accurately, we know it learned the real pattern — not just memorized the answers. Like taking a test on material you studied!

Inference = Using it for real. Now the trained model can predict scores for any number of study hours. "If I study 7 hours, what score will I get?" That's inference — using what the model learned to make predictions on brand new inputs!

Remember: Training = finding the line. Testing = checking the line. Inference = using the line.

ML Is Like Studying for a Test

The ML process maps perfectly to your own experience:

📚 Training = Studying your notes and textbook

You're absorbing patterns: "When this comes up, the answer is usually that."

🧪 Testing = Taking a practice test

Did you really learn, or did you just memorize? The practice test shows you.

🔮 Inference = Taking the real exam

New questions you've never seen — you use what you learned to figure them out.

What if you only memorized? You'd ace the practice test but fail the real one. ML has the same problem! It's called "overfitting" — when a model memorizes the data instead of learning the pattern.

From Lines to Intelligence

Our line is the simplest ML model. But real AI uses the same idea — scaled up massively!

📏

What We Did

1 input (hours) → 1 output (score)
2 parameters (m, b)
6 data points

🧠

What ChatGPT Does

Millions of inputs → next word
175 billion parameters
Trillions of words of text

Same idea, different scale. We found the best m and b for a line. ChatGPT found the best values for 175 billion parameters — but the process is the same: show data, find patterns, make predictions.

💡 "Machine Learning is finding patterns in data. AI is the umbrella. Gen AI is when those patterns are good enough to create something new."
